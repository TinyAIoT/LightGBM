# Latency Experiments (Prototype)

In this directory you can find experiments to measure the latency of a ToaD model and a basic LightGBM model. The models are deployed by Arduino code. It was tested on two different devices, [XIAO ESP32-S3](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/) and [Arduino Nano 33 BLE](https://store.arduino.cc/collections/nano-family/products/nano-33-ble-rev2). The results in the runtimes folder are the inference time accumulated for 500 predictions.

Information on how to deploy Arduino code on such devices can be found in the [Arduino documentation](https://support.arduino.cc/hc/en-us/articles/4733418441116-Upload-a-sketch-in-Arduino-IDE). Intermediate results over multiple runs o the first version of the prototype show that latency for ToaD is in the range of XX to XX micro seconds, depending on the hardware. This equals a decrease in latency of a factor between 4 to 10. Regarding the overall latency in deployment use cases where the device needs to be woken up, collect data with sensors and transmit results afterward this latency increase is negligible.
